작물재배관리
- 환경관리는 환기와 난방설정치를 작물 생육상황에 맞추어 수정할 계획이지만, 현재까지는 
큰 무리없이 재배관리가 가능함(건묘육성 + 양액관리 + 홀몬 효과)
- 꽃밭침마름현상과 정식후 1화방 수확직전까지 런너를 통해 균인 감염되어 고사하는 주가 
다수 발생함 -> 원인 분석위해 병원체 샘플림 분석 필요
농가의견
- 육묘기 근관부를 키우기 위해 노력한 결과 정식후에도 생육이 왕성하고 수확량이 높으며 
품질도 우수함

환경관리
- 작물 생육상황과 광, 온도, 습도 데이터를 분석하여 환기, 난방, 급액 등 설정치를 수정하
면서 양호하게 관리하고 있음 -> 유동팬 작동 여건, 시간 범위 등에 대한 구체적 가이드

- 부탄가스 직화 탄산가스발생기를 사용하여 탄산가스 시비 시범사업을 추진중임

는 세균병으로 의심됨 -> 동수화제, 배지소독 등이 필요
- 꽃받침 마름병(진균류?로 추정) -> 일조부족, 근권생육불량기에 광합성 부족으로 인한 영
양 생리장애로 판단됨
